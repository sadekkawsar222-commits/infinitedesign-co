Talk about UI/UX Design

Design here starts with people, not screens. We run contextual interviews, usability tests and analytics reviews before anyone opens a design tool — because the most expensive redesign is the one that solves a problem nobody had.

The output is not a folder of pictures. It is a documented design system with tokens, states, motion rules and accessibility annotations, wired to the same component names your engineers use in code.

What the work includes

  • Discovery research, interviews and stakeholder workshops
  • Journey mapping and information architecture
  • Wireframing, prototyping and usability testing
  • Visual design and interaction design
  • Design systems with tokens and documentation
  • Accessibility review and inclusive design
  • Design QA through to production release
  • Bangla typography and localisation review

What you receive

  • Research report with prioritised findings
  • Clickable prototype covering core journeys
  • Figma design system with usage documentation
  • Handoff specs, motion notes and design QA support

Questions we get asked
